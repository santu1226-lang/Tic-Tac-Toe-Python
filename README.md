# Tic-Tac-Toe Python
BCA mini project | LMCST | Two-player console game using object-oriented Python.

## Run
Requires Python 3. No external packages.

```sh
python tic_tac_toe.py
```
Players X and O take turns selecting positions 1–9. Three matching symbols in a row, column or diagonal win. A full board without a winner is a draw. Invalid moves are rejected.

## Test
```sh
python -m unittest test_game.py
```

## Files
- `tic_tac_toe.py`: game source
- `test_game.py`: unit tests
- `Project_Report.pdf`: project report

This is an offline game; no login, database, credentials or tokens are required.
